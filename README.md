# Lumivo OS — descargas

Instaladores de **Lumivo OS**, el launcher (pantalla de inicio) de [Grupo Lumivo](https://grouplumivo.com) para Android TV.

Cada versión está en **Releases**. Lumivo OS se actualiza solo desde aquí; no hace falta descargar nada a mano.

- Firmado por Grupo Lumivo (Zapopan, Jalisco). Android solo instala actualizaciones con la misma firma.
- El código fuente no es público.
- Dudas: WhatsApp +52 33 1852 8350 · grouplumivo.com

## Catálogo de películas y series

La sección «Cine y series» de Lumivo OS lee `catalogo.json` de la rama [`catalogo`](../../tree/catalogo), que se genera una vez al día con `catalogo/generar_catalogo.py` (GitHub Actions).
